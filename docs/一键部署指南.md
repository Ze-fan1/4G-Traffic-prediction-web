# 一键部署指南 — 让别人也能用你的完整系统

## 当前状态
- ✅ 前端: GitHub Pages → `https://ze-fan1.github.io/4G-Traffic-prediction-web/`
- ❌ 后端: 只有你本地 `localhost:8000`，别人无法访问

## 部署方案: Hugging Face Spaces (最推荐)

**为什么选它：**
- 免费 CPU 版够用（推理秒级完成，训练慢但能跑）
- 支持 Docker，可以把整个环境打包
- 自带 HTTPS 域名
- 需要 GPU 时一键升级（$0.6/小时）

```bash

# 2. 复制后端代码

# 注意: 复制后需要修改 backend 里的路径引用（见下文）

# 3. 复制 TSL 库
cp -r "C:\Users\Admin\Desktop\网络流量预测项目新修改2\Time-Series-Library-main" .

# 4. 创建 Dockerfile
```

### Dockerfile（新建文件 `C:\Users\Admin\Desktop\deploy\Dockerfile`）

```dockerfile
FROM pytorch/pytorch:2.3.1-cuda12.1-cudnn8-runtime

WORKDIR /app

# 安装 Python 依赖
RUN pip install --no-cache-dir \
    fastapi==0.111.0 uvicorn==0.30.1 \
    numpy==1.26.4 pandas==2.2.2 scikit-learn==1.5.0 \
    openpyxl==3.1.5 xgboost==2.1.0 statsmodels==0.14.2 \
    python-multipart==0.0.9

# 复制 TSL 库
COPY Time-Series-Library-main /app/Time-Series-Library-main

# 复制后端（已修改路径的版本）
COPY backend /app/backend

WORKDIR /app/backend
EXPOSE 7860

CMD ["uvicorn", "server:app", "--host", "0.0.0.0", "--port", "7860"]
```

## 第二步: 修改后端路径（适配 Linux 容器）

在部署到 HF Spaces 之前，需要把后端代码里的 Windows 绝对路径改成相对路径。

修改 `backend/server.py` 中这一行：

```python
# 改前（Windows 绝对路径）
TSLIB = Path(__file__).resolve().parent.parent / ".." / "网络流量预测项目新修改2" / "Time-Series-Library-main"

# 改后（容器内相对路径）
TSLIB = Path(__file__).resolve().parent.parent / "Time-Series-Library-main"
```

同样修改 `backend/data_pipeline.py`、`backend/model_loader.py`、`backend/model_registry.py`、`backend/preset_curves.py`、`backend/train_runner.py` 中的 `TSLIB_ROOT`。

**批量替换命令**（在 `C:\Users\Admin\Desktop\deploy\backend` 下执行）：
```bash
# Git Bash 中执行
for f in server.py data_pipeline.py model_loader.py model_registry.py preset_curves.py train_runner.py inference_engine.py; do
  sed -i 's|Path(__file__).resolve().parent.parent / ".." / "网络流量预测项目新修改2" / "Time-Series-Library-main"|Path(__file__).resolve().parent.parent / "Time-Series-Library-main"|g' "$f"
done
```

## 常见问题

### Q: 训练太慢怎么办？
A: 在 Space 设置中升级硬件到 `T4 GPU`（约 $0.6/小时），训练速度提升 50-100 倍。不用时切回 CPU（免费）。

### Q: 模型文件太大怎么办？
A: HF Spaces 仓库限制 50GB。模型文件建议用 Git LFS 管理，或者从 Google Drive/OSS 下载。

### Q: 能不能完全免费？
A: Hugging Face Spaces CPU Basic 完全免费。推理足够快，训练会慢（DL 模型约 30-60 分钟/epoch vs GPU 30秒）。

### Q: 换域名？
A: HF Spaces 提供 `用户名-空间名.hf.space` 的 HTTPS 域名。也可以绑定自己的域名。
